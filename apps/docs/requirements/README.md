# Requisitos e ciclo de vida

O WaterfallLab acompanha sete fases sequenciais do ciclo Cascata:

1. F01 — Levantamento de Requisitos.
2. F02 — Análise.
3. F03 — Projeto e Arquitetura.
4. F04 — Implementação.
5. F05 — Testes e Validação.
6. F06 — Implantação.
7. F07 — Operação e Manutenção.

Cada fase deverá registrar responsável, datas, entregáveis, critérios de
aceitação, documentos, status e histórico. A aprovação de Stage Gate deverá
bloquear formalmente o início da próxima fase até que todos os critérios
obrigatórios estejam atendidos. Revisões e mudanças devem preservar trilha de
auditoria. Estas são diretrizes do produto, não funcionalidades já
implementadas pela estrutura inicial.

# Componentes

- `ui/`: primitivos (`Button`, `Card`, `Modal`...) e ícones SVG.
- `charts/`: gráficos SVG (linha, barras, rosca).
- `layout/`: `AppShell` (menu lateral e cabeçalho).
- `shared/`: cabeçalho de página, cartão de métrica, campo e página padrão.
- `dashboard/`: linha do tempo e editor de atividades.
